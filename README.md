# ACN Portfolio Simulator

A private planning workspace. It answers one question: **what is my Accenture position worth, and how would a partial reallocation compare?** It is a simulator: there is no brokerage connection and it never executes trades.

Built from *ACN Portfolio Simulator — Sites Build Prompt v1.1*.

## What's here

| Part | Where | Notes |
|---|---|---|
| Calculation engine | `src/engine/` | Pure ES modules. The UI and every test import the same code. |
| Server | `server/` | Node ≥ 20 with no runtime dependencies. Serves the static app, owner auth, owner-scoped record storage and the quote/history adapter. |
| UI | `public/` | Vanilla JS. Hash routes (`#/myacn/acn/today`, `#/central/downside`, …), an offline shell via service worker, and one SVG chart per view. |
| Tests | `tests/` | `node:test` checks for the engine, server and quotes, plus Playwright browser tests of the rendered site. |
| Ledger | `docs/TEST_LEDGER.md` | Control inventory generated by the browser run: expected change, actual result, pass/fail. |

### Screens
- **Four tabs:** My ACN, Low, Central and High. Each tab has its own inputs, dated baselines, runs and results. Balances are never added together, and ACN never appears in a proceeds tab.
- **My ACN** has three views, each reachable in one tap: **100% ACN**, **100% Diversified** and **Custom Split**. Each view has Today, Projections and Downside.
- **Default screen:** My ACN → 100% ACN → Today. It shows $800,000 labelled *Placeholder* and derived shares labelled *Estimated*. **Update my ACN position** is visible on this screen.

### Replacing the placeholder
Tap **Update my ACN position** and enter either:
- an opening dollar amount, or
- your actual share count, an as-of date and an ACN reference price (verified or typed).

Preview the result, then confirm. This starts a new dated baseline for all three views with the same capital and timestamp. The earlier placeholder run, its history and the other three tabs are kept.

## Run locally

```bash
npm run create-user -- you@example.com "a-long-password"   # owner account (stored scrypt-hashed in ./data)
TWELVEDATA_API_KEY=... npm start                            # http://localhost:8787
```

### Environment

| Variable | Purpose |
|---|---|
| `TWELVEDATA_API_KEY` | Server-side key for [Twelve Data](https://twelvedata.com/docs): batch `/quote`, `/dividends`, `/splits` and `/time_series`. Without it, quotes show as *Unavailable*. You can still enter dated manual quotes, and projections work without a feed. |
| `QUOTE_ENTITLEMENT` | `realtime` only if your plan grants real-time data for display. Otherwise leave it unset, and quotes are labelled *Delayed*. "Live" appears only with a real-time entitlement and a fresh timestamp. |
| `DATA_DIR` | Persistent, writable volume for accounts, sessions and records. If it isn't writable, the app reports account storage as **blocked** and shows this setup step. |
| `COOKIE_SECURE` | Defaults to on when `NODE_ENV=production`. Serve over HTTPS. |
| `PORT` | Default `8787`. |

BTC/USD falls back to the Coinbase Exchange public ticker, which is timestamped and trades 24/7. Only ticker symbols from the fixed instrument list are ever sent to a provider. Request logs record only the method, path, status and duration, never query strings, bodies or amounts.

## Deployment status and verification limits

- **Not deployed.** This build was produced in a sandbox that cannot publish a ChatGPT Site or any other private host. The source is deployment-ready.
  - **Next step:** deploy to a Node host with a persistent volume. Set `DATA_DIR`, `TWELVEDATA_API_KEY` and `NODE_ENV=production`, put it behind HTTPS, and run `npm run create-user` once.
  - The site is owner-only because every API route requires the owner's session, and pages are `noindex`.
  - The browser suite can then be pointed at the deployed URL to verify it.
- **No live provider request was made.** The sandbox's network policy refused connections to the quote providers (HTTP 403 at the proxy). All quote, distribution and failure-mode results come from the mock provider or a recorded-format fixture.
  - Live ACN and BTC/USD quotes, timestamps, currency and distribution coverage are **unverified**.
  - Twelve Data field mappings (`timestamp`/`last_quote_at`, `is_market_open`, dividend amounts) should be confirmed against a real response.
  - Verify ETF instrument identity with each issuer before release.
- **The visual reference terminal was not consulted.** The design follows the brief instead.
- **Environments actually used:** headless Chromium (Playwright) at 320, 390, 820 and 1440 px and 1180×820 tablet landscape, emulating touch. Two-session sync used isolated browser contexts against one local server. **No physical iPhone or iPad was tested.**
